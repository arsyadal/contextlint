# Security Policy

## Supported Versions

ContextLint is pre-1.0. Use the latest published version for fixes.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory or contacting the maintainer.

Do not paste secrets, API tokens, private keys, or sensitive repository content into public issues.

## Privacy

ContextLint runs locally by default.

- No telemetry.
- No network calls during scan.
- No file contents sent to external services.
- No API key required.
